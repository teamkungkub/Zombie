# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
A playable first-person zombie survival shooter. The user requested realistic shooting and chose fighting zombies.

## Capabilities and Constraints
Build in the existing Next.js 16 / React 19 repository. Use browser-based 3D. Realistic aiming, recoil, ammunition, reloading and moving enemies are implementation choices. Thai instructions support the user's language. No multiplayer or paid services requested.

## Open Decisions
NIGHTFALL, the industrial quarantine zone, and the visual treatment are implementation choices.
