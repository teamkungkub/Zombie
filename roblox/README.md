# ชุดข้อมูล NIGHTFALL สำหรับ Roblox Studio

ชุดนี้เก็บค่าจากเกมเว็บปัจจุบันเพื่อใช้ตอนย้ายเกมไป Roblox เวอร์ชันที่เล่นได้ใน Roblox ยังต้องสร้างฉากและระบบเกมด้วย Roblox Studio และ Luau โดยใช้ข้อมูลชุดนี้เป็นจุดเริ่มต้น โค้ด Next.js, Three.js และ Web Audio เป็นระบบของเวอร์ชันเว็บ ดูโครงสร้างของ Roblox ใน [Roblox Data Model](https://create.roblox.com/docs/projects/data-model)

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| [NightfallConfig.luau](NightfallConfig.luau) | คัดลอกลง ModuleScript ชื่อ `NightfallConfig` ใน `ReplicatedStorage` แล้วเรียกด้วย `require` |
| [nightfall-data.json](nightfall-data.json) | ใช้ดูค่าหรือเทียบผลกับเวอร์ชันเว็บ มีชุดอ้างอิงด่าน 1–12 ครบทั้งสามระดับความยาก |

เมื่อปรับค่าด่าน ปืน บอส หรือกระสุนในเกมเว็บ ให้รัน `npm run export:roblox` จากรากโปรเจกต์เพื่อสร้างไฟล์ใหม่ และใช้ `npm run export:roblox -- --check` เพื่อตรวจว่าไฟล์ตรงกับโค้ด

## ลองอ่านข้อมูลใน Studio

สร้าง ModuleScript ชื่อ `NightfallConfig` ใน `ReplicatedStorage` แล้ววางเนื้อหาจากไฟล์ Luau เปิด Command Bar เพื่อทดสอบ

```lua
local config = require(game:GetService("ReplicatedStorage"):WaitForChild("NightfallConfig"))
local first = config.referenceStages.survivor[1]
assert(#config.zones == 4 and #config.weaponSlots == 5)
assert(#first.enemies == 6 and first.bossKind == "slam")
assert(config.ammoDrops.roundsByWeapon.shotgun == 1)
print(config.title, config.zones[1].name, first.bossHealth)
```

## ระบบที่ต้องย้ายตอนสร้างเกม Roblox

เสนอให้เริ่มจากโหมดผู้เล่นเดี่ยวและใช้ Place เดียว โดยสลับฉากทั้งสี่หลังเดินผ่านประตู จะได้เก็บสถานะกระสุนและของในรอบเดียวกันขณะเปลี่ยนโซน หากต้องการเล่นหลายคน ค่อยกำหนดกติกาแบ่งของ การตาย และการเดินผ่านประตูร่วมกัน

| งาน | จุดอ้างอิงและเกณฑ์ตรวจ |
| --- | --- |
| ฉากทั้งสี่ | สร้างลานกักกัน สถานีรถไฟร้าง โรงหล่อ และสวนพฤกษศาสตร์เป็น Model แยกกัน กำหนดจุดเกิดผู้เล่น ศัตรู บอส กล่องปืน วงเขียว และประตู ระยะในไฟล์เป็นหน่วยของเกมเว็บ ให้กำหนดอัตราแปลงเป็น studs เดียวกันสำหรับฉากและพื้นที่โจมตี |
| โหมดเอาตัวรอด | ให้เซิร์ฟเวอร์จัดลำดับ **ฝูงซอมบี้ → บอส → วงเขียว → ประตู → โซนถัดไป** หลังชนะบอสให้เวลา 25 วินาทีไปเปิดประตู และเก็บปืนกับกระสุนข้ามโซน ด่าน 1–12 ในไฟล์ใช้เทียบผล ใช้ `stagePlan` และ `stageEnemyScaling` จาก `lib/nightfall/rules.ts` เพิ่มเลือด ความเร็ว ความแรง เวลา และกระสุนตามด่าน โดยจำกัดจำนวนซอมบี้พร้อมกัน |
| ปืนและของเก็บ | ย้ายการสลับปืน 1–5 การรีโหลด กระสุนแยกตามปืน กล่องประจำโซน และการกด Q วนเลือกของที่มี ระเบิดกดค้างแล้วปล่อยเพื่อโยน ยาฟื้น 35 หลังจบท่าฉีดยา 1.5 วินาที ใช้ `equipment.injectionTiming` สำหรับจังหวะยกแขน กดลูกสูบ และดึงเข็มออก เครื่องดื่มชูกำลังต้องกดใช้เอง และกล่องกระสุนเติมเข้าปืนที่ตรงชนิด |
| บอสและของดรอป | ใช้ `bosses` กับ `bossCombos` สำหรับท่าปกติ เมื่อเลือดถึง `bossUltimateHealth` ให้ใช้ท่าใน `bossUltimates` ได้ครั้งเดียว แสดงพื้นที่กับเสียงเตือนก่อนโจมตี และตรวจให้ขอบเขตตรงกับพื้นที่ที่โดน ใช้ `bossCrashRadius` สำหรับระเบิดปลายทางและ `bossUltimateMortarSpread` สำหรับดาวเพลิง เมื่อซอมบี้ตายให้สุ่มของตาม `equipment.drops` เมื่อบอสตายให้สุ่มปืนจาก `bossWeaponPools` ตามชนิดบอส |
| ท่าเคลื่อนไหวซอมบี้ | ใช้ `enemyTuning.gaits` อ้างอิงองศาเอนตัว ความยาวก้าว และน้ำหนักฝีเท้า ให้วงจรท่าเดินเดินหน้าตามระยะที่เคลื่อนที่จริง แล้วเล่นเสียงเมื่อเท้าลงพื้น |
| ท่าโจมตีซอมบี้ | ใช้ `enemyTuning.melee` และ `hunterPounce` กำหนดท่าเตือน ระยะโจมตี และความกว้างของพื้นที่โดน ล็อกทิศเมื่อเริ่มง้าง ให้ตัวใหญ่ง้างสองแขนก่อนทุบ และให้ตัววิ่งย่อก่อนกระโจน ตรวจโดนตลอดแนวกระโจนและหยุดที่กำบัง |
| คาตานะ | ให้กด Q วนตาม `equipment.order` โดยคาตานะเลือกได้เสมอและข้ามของใช้ที่หมด คลิกซ้ายเมื่อถือคาตานะหรือกด V เพื่อฟันทันที ใช้ค่าใน `equipment.knife` ให้เซิร์ฟเวอร์ตรวจพละกำลัง ระยะ และที่กำบัง ซอมบี้ทั่วไปที่รอดจากการฟันจะหยุดท่าเตรียมโจมตีและถอยตามค่า `staggerSeconds` กับ `pushback` ให้หยุดถอยเมื่อชนที่กำบัง แล้วส่งผลให้ฝั่งผู้เล่นเปิดเสียงฟันโดนหรือฟันพลาด |
| เอฟเฟกต์ยิง | ใช้ `kick` และ `fireFx` ของปืนแต่ละกระบอกอ้างอิงจังหวะถีบและคืนตัว วางแสงกับควันที่ปากกระบอก และปล่อยปลอกจากตำแหน่งข้างตัวปืน แสดงเอฟเฟกต์เมื่อยิงและเสียกระสุนหนึ่งนัด |
| ห้องและตัวละคร | ใช้ `characters` และ `multiplayer` อ้างอิงตัวละคร 3 แบบกับห้องรหัส 6 หลัก ผู้เล่นในห้องเดียวกันเข้าสนามเดียวกัน ให้เซิร์ฟเวอร์ตรวจการยิงโดนเพื่อนและสิ่งกีดขวาง |
| มือและรีโหลด | ให้มือขวาอยู่ที่ด้ามปืน ส่วนมือซ้ายตามตำแหน่งแม็กหรือกระสุน ใช้ `reload.animation` สำหรับจังหวะหยิบ ใส่ และปล่อยมือ ลูกซองทำซ้ำทีละนัดตาม `reload.shotgunShellSeconds` |
| กระสุนกระทบฉาก | แยกวัสดุจากผล Raycast ให้ปูนมีฝุ่นและเสียงทึบ ส่วนเหล็กมีประกายกับเสียงกังวาน ใช้ `surfaceImpacts` กำหนดอายุและจำนวนรอย ติดรอยกับชิ้นส่วนที่โดนเพื่อให้ขยับตามประตู |
| โค้ดและหน้าจอ | ใช้ `ServerScriptService` เก็บสถานะรอบ กระสุน การโดนโจมตี และการเปิดประตู ฝั่งผู้เล่นดูแลกล้อง ปุ่ม HUD และเอฟเฟกต์ ส่งคำขอผ่าน RemoteEvent แล้วให้เซิร์ฟเวอร์ตรวจสถานะ ระยะ และความถี่ก่อนยอมรับ ดู [Remote events](https://create.roblox.com/docs/scripting/events/remote) และ [การตรวจข้อมูลระหว่าง client กับ server](https://create.roblox.com/docs/scripting/security/client-server-boundary) |
| ภาพและเสียง | สร้างฉาก อาวุธ และตัวละครจากชิ้นส่วนเรียบง่ายใน Studio ก่อน ส่วนโมเดลหรือเสียงที่เตรียมเป็นไฟล์เพิ่มเติมให้ลงทะเบียนและทดสอบในเกม Roblox ตาม [Studio Importer](https://create.roblox.com/docs/studio/importer) |

## ก่อนเปิดให้คนเล่น

1. ทดสอบด่านแรกให้ครบตั้งแต่เริ่มเกมจนไปถึงโซนที่สอง แล้วทดสอบต่อจนครบสี่โซน รวมถึงหมดเวลา ตาย เริ่มใหม่ และสลับปืนระหว่างรีโหลด
2. ทดสอบปุ่มและการอ่านคำเตือนของบอสบนคีย์บอร์ดกับมือถือ และลองเล่นใน Studio โหมดทดสอบฝั่งเซิร์ฟเวอร์และผู้เล่น ดู [Studio testing modes](https://create.roblox.com/docs/studio/testing-modes)
3. เมื่อตัวเกมพร้อม ให้สร้างเวอร์ชันทดสอบใน Studio และเชิญผู้ทดสอบ ก่อนเปิดสาธารณะให้ตรวจคุณสมบัติบัญชีและกลุ่มผู้เล่นเป้าหมายล่าสุด ตอบแบบประเมินตามภาพ เสียง และความรุนแรงในเกมเวอร์ชันที่จะปล่อยจริง ดู [วิธีเผยแพร่เกม](https://create.roblox.com/docs/production/publishing/publish-games-and-places) และ [เกณฑ์จัดระดับเนื้อหา](https://create.roblox.com/docs/production/promotion/content-ratings)
